# TypeScript Lens

Use this note when TypeScript materially participates in the audited surface. It sharpens the generic protocol without supplying a smell checklist.

## Surface

The default implementation manifest contains handwritten `*.ts`, `*.tsx`, `*.mts`, and `*.cts` files. Include `tsconfig`, package metadata, schemas, and configuration when they materially define the scoped component. Generated clients and declarations, build output, coverage, snapshots, fixtures, and dependencies remain outside the audit manifest unless explicitly included.

## Semantic Posture

Treat TypeScript as a real static language while respecting its runtime erasure. Discriminated unions, branded or opaque types, literal worlds, `readonly`, precise generics, `satisfies`, `as const`, `never` exhaustiveness, template literal types, and typed lookup tables are available when they compress real laws.

Static and runtime truth must agree. Types that merely assert unvalidated external data, runtime guards compensating for avoidable internal vagueness, and broad object shapes may all multiply obligations. Conversely, validation at a genuine trust boundary is not defensive theater.

Modern TypeScript and strict compiler options are preferred when the current project contract permits them. Toolchain, runtime, bundler, or browser-target migration is outside the semantic envelope unless authorized.

JSON, HTTP, GraphQL, storage, environment, database, and third-party SDK values may remain unknown or primitive at their boundaries. Narrow once and avoid dragging transport uncertainty through the internal model.

## Navigation

Use the TypeScript language server, project references, package graph, runtime entrypoints, and textual search together. Trace both type flow and runtime flow from whichever anchor resolves the clique's question.

## Implementation Phase

When implementation is authorized, use the repository's existing typecheck, test, format, lint, and build commands. The audit phase itself must not depend on executing or modifying the target tree.
